
# CareLog - Dashboard Kader Posyandu

## Deskripsi
CareLog merupakan sistem informasi Posyandu.
Project ini merupakan implementasi halaman Dashboard
Kader Posyandu menggunakan React.

## Teknologi
- React
- Vite
- JavaScript
- CSS
- Lucide React

## Fitur
- Sidebar navigasi
- Header Dashboard
- Statistik data warga
- Statistik pemeriksaan
- Aktivitas Posyandu
- Responsive layout

## Cara Menjalankan Project

1. Clone repository.
2. Jalankan npm install.
3. Jalankan npm run dev.
4. Buka alamat localhost yang muncul di terminal.

## Build
Jalankan npm run build untuk membuat versi production.
